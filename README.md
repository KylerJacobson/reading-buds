## Project Overview

This is a personal project designed act as a reading companion. The goal is to utilize large language models to analyze an article / book review written by the user and discuss their opinions / conclusions as a way to sharped the users comprehension and opinions. The user will be able to select a number of different "companions" which will be user select LLMs with custom prompt logic. The user will provide API keys for the various providers they would like to utilize.

The primary user of this application is a software engineer so this application will also provide a way to compare and evaluate different models ability to critically analyze a broad array of material.
